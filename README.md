
# NIAMEY MEGA

NIAMEY MEGA is an online airtime recharge platform designed for Niger Republic.

Our goal is to make mobile airtime recharge simple, fast, and convenient.

## Features

- Direct Airtime Recharge
- Multiple Network Support
- Airtel Niger
- Moov Africa Niger
- Zamani Telecom
- Mobile-Friendly Website
- Secure Payment Integration (Coming Soon)
- Automatic Airtime Delivery (Coming Soon)
- Transaction History (Coming Soon)
